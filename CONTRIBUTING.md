# Contributing

Thanks for helping improve BPSMV Resource Hub.

## Good Contributions

- Clean notes and previous year papers.
- Clear subject, semester, and branch metadata.
- Verified job, internship, scholarship, and challenge updates.
- Bug fixes that keep existing student flows working.
- Small UI improvements that make study material easier to find.

## Development Flow

1. Create a focused branch.
2. Keep changes small and related.
3. Run the relevant backend tests or frontend build.
4. Check that secrets, logs, uploads, and generated builds are not staged.
5. Write a short commit message that says what changed.

## Content Guidelines

- Upload only material you are allowed to share.
- Name files clearly.
- Avoid duplicate resources.
- Keep discussions respectful and useful for students.

## Code Guidelines

- Prefer simple, readable changes.
- Keep API responses consistent.
- Validate user input on the server.
- Protect student data before adding public fields.
