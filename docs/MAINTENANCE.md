# Maintenance Checklist

Use this checklist when updating the project.

## Weekly

- Review new resource uploads.
- Remove duplicate, broken, or low-quality submissions.
- Check gift issue reports.
- Add useful job, internship, scholarship, or challenge links.

## Before Deploying

- Run backend tests.
- Build the frontend.
- Confirm no `.env`, log, upload, or build output files are staged.
- Check that production secrets are set in hosting dashboards.

## Data Care

- Keep subject names consistent.
- Avoid deleting user activity unless it is spam or abuse.
- Back up MongoDB before large manual changes.

## Security Care

- Rotate credentials after team changes.
- Keep upload limits conservative.
- Review public profile fields before exposing new user data.
